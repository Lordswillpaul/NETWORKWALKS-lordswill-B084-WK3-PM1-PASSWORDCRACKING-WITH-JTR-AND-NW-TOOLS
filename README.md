Week 3 – Project Module 1: Password Cracking with John the Ripper

Objective: Crack password hashes using John the Ripper (JTR) and the Networkwalks lab tools to demonstrate password security weaknesses and cracking methodology.

• Tools Used
1. John the Ripper (Jumbo 1.9.0, Windows x64 build)

2. Johnny (GUI front-end for JTR)

3. Network walks lab environment

• Process

1. Set up John the Ripper (CLI + Johnny GUI) on a Windows machine.

2. Loaded the target password hash file into Johnny.

3. Ran the cracking attack using JTR's default wordlist/rules.

4. Successfully recovered the plaintext password(s), confirming the hash(es) were weak/crackable.

5. Captured flags confirming successful completion of the exercise.
